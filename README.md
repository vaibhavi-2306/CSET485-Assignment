# CSET485 Assignment 1 – Adult Income Analysis

## Overview
This project analyzes the Adult Census Income dataset to study income prediction, model performance, subgroup effects, omitted variable bias, and fairness in AI.

## Dataset
- **File:** `adult.csv`
- **Target:** Income (`<=50K` or `>50K`)

## Tools Used
- Python
- Google Colab
- Pandas, NumPy, Matplotlib
- Scikit-learn, Statsmodels

## How to Run
1. Download the notebook.
2. Open it in [Google Colab](https://colab.research.google.com/).
3. Upload `adult.csv` when prompted.
4. Run the notebook cells in order.

## Contents
- Data preprocessing and exploration
- Linear and logistic regression
- Subgroup analysis
- Omitted variable bias analysis
- Adversarial subset analysis
- Fairness metrics and trade-off visualization
